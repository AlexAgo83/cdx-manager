# CDX Manager 0.18.6

## Features

- Launches can use an explicit `--dir`; each run records its directory for status and tray surfaces.
- The Logics tray card derives repositories from active runs and shows basename-only rows.
- `cdx update` names its install prefix, while `cdx tray doctor` reports the companion CDX command and hook-store alignment.
- Windows Terminal, GNOME Terminal, and Konsole open new tabs where their documented interfaces support it; other terminals retain the working window fallback.
